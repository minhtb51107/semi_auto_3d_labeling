# Semi-Auto 3D Cuboid Labeling

> Reduce manual redraw effort for 3D cuboid annotation of LiDAR point-cloud sequences.

## Overview

This tool propagates a human-confirmed 3D cuboid annotation from one LiDAR
frame to subsequent frames using ICP-based point-cloud alignment, with a
constant-velocity motion prior as fallback. The predicted cuboids are exported
in CVAT-compatible format for human review and correction.
